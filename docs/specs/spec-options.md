# Spec: 設定ページ（プロジェクト名・保存時動作）

> **免責**: この Spec は完全ではない。機能変更があれば随時更新する。実装とズレを見つけたら修正 PR を送ってほしい。
> **著者**: cosense-link-clipper / 最終更新: 2026-05-22

## 概要

拡張機能の設定を管理するフルページの Options ページ。
Cosense プロジェクト名と保存時の動作（ページを開くかどうか）を設定する。
設定は `chrome.storage.sync` に保存され、Chrome アカウントでのデバイス間同期が有効になる（→ [ADR 003](../adr/003-storage-sync.md)）。

## 機能仕様

### シナリオ 1: 佐藤さん、初めて拡張機能をインストールして設定する

佐藤さんは拡張機能をインストールした。設定ページが自動的に開く。

1. 設定ページが開く。プロジェクト名の入力欄が空になっている
2. 入力欄に `scrapbox.io/` のプレフィックスが表示されており、その横に入力フィールドがある
3. `my-notes` と入力する。入力直後に「保存先: <https://scrapbox.io/my-notes/...」というプレビューが表示される>
4. 「保存」ボタンをクリックする（または Enter キーを押す）
5. 「✓ 設定を保存しました」の成功メッセージが 3 秒間表示される

### シナリオ 2: 鈴木さん、バックグラウンド保存に切り替えたい

鈴木さんは保存のたびに Cosense のタブが開いて邪魔だと感じている。

1. 設定ページを開く
2. 「保存後にCosenseのページを開く」チェックボックスのチェックを外す
3. 「保存」ボタンをクリックする
4. 以降、ポップアップと右クリックメニューどちらからでもバックグラウンド保存になる

### シナリオ 3: 田中さん、プロジェクトを変更する

田中さんは Cosense のプロジェクトを引っ越した。

1. 設定ページを開く。既存のプロジェクト名が入力欄に入っている
2. 新しいプロジェクト名に書き直す
3. 「保存」ボタンをクリックする
4. 次にポップアップからクリップするときに新しいプロジェクトに保存される

### 非ゴール

- **複数プロジェクトの切り替え**: 保存先プロジェクトは 1 つのみ。複数プロジェクトへの振り分けは対象外
- **Cosense プロジェクトの存在確認**: 入力されたプロジェクト名が実際に存在するかをリアルタイムで検証しない
- **プロジェクト一覧の取得・選択 UI**: Cosense API は認証が必要なため自動取得はしない（→ [ADR 002](../adr/002-cosense-url-api.md)）

### 未解決課題

- プロジェクト名のバリデーション: 現在は空文字列チェックのみ。Cosense のプロジェクト名として不正な文字列（スペース含みなど）を入力した場合の挙動が未定義
- 「保存時の動作」設定を変更したとき、既に開いているポップアップに設定変更が反映されない（ポップアップを再度開けば反映される）

## 詳細仕様

### エントリーポイント

`src/entrypoints/options/App.tsx`

1. `useEffect` でマウント時に `getSettings()` を呼び出して既存設定を取得
2. 取得した値を `projectName` / `openPageOnSave` の state にセット
3. 「保存」ボタンクリック（または Enter キー）時:
   - `isValidProjectName` でプロジェクト名を検証（空・空白のみは無効）
   - 有効な場合、`saveProjectName` と `saveOpenPageOnSave` を `Promise.all` で並行実行
   - 成功時は `saveStatus = "saved"` にして 3 秒後に `"idle"` に戻す
   - 失敗時は `saveStatus = "error"` にして 3 秒後に `"idle"` に戻す

### 状態管理

| state | 型 | 初期値 | 説明 |
|---|---|---|---|
| `projectName` | `string` | `""` | 入力中のプロジェクト名 |
| `openPageOnSave` | `boolean` | `true` | 保存時の動作設定 |
| `saveStatus` | `SaveStatus` | `"idle"` | `"idle"` / `"saving"` / `"saved"` / `"error"` |
| `isLoading` | `boolean` | `true` | 設定読み込み中フラグ |

### バリデーション

- `isValidProjectName`: 空文字列・空白のみの場合 `false` を返す（`src/lib/cosense.ts`）
- 無効時は「保存」ボタンが非活性になる

### ストレージキー

| キー | 型 | デフォルト |
|---|---|---|
| `cosenseProjectName` | `string` | `""` |
| `openPageOnSave` | `boolean` | `true` |
