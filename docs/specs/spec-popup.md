# Spec: ポップアップからのクリップ操作

> **免責**: この Spec は完全ではない。機能変更があれば随時更新する。実装とズレを見つけたら修正 PR を送ってほしい。
> **著者**: cosense-link-clipper / 最終更新: 2026-05-22

## 概要

ツールバーの拡張機能アイコンをクリックして開くポップアップ UI から、
現在開いている Web ページのタイトルと URL を Cosense の新規ページとして保存する機能。

## 機能仕様

### シナリオ 1: 田中さん、気になった記事を Cosense に保存する

田中さんはエンジニアで、読んでいた技術記事を Cosense のメモに残したい。
ツールバーの Cosense Link Clipper アイコンをクリックする。

1. ポップアップが開く。現在のページタイトルと URL が表示されている
2. 「Cosenseに保存」ボタンをクリックする
3. 新しいタブで Cosense のページ作成画面が開き、タイトルと URL がセットされている
4. ポップアップは 0.8 秒後に自動的に閉じる
5. 田中さんは Cosense 側でページを確認し、保存ボタンを押す

### シナリオ 2: 鈴木さん、設定が未完了でポップアップを開く

鈴木さんは拡張機能をインストールしたばかりでプロジェクト名を設定していない。
アイコンをクリックしてポップアップを開く。

1. ポップアップが開く。「Cosenseのプロジェクト名が設定されていません」という警告が表示される
2. 「設定を開く →」リンクをクリックする
3. 設定ページが新しいタブで開き、ポップアップが閉じる
4. 設定ページでプロジェクト名を入力・保存すれば次回から使えるようになる

### シナリオ 3: 山田さん、今開いているページから離れずに保存したい

山田さんは読み途中の長い記事を Cosense に保存したいが、ページを離れたくない。
設定ページで「保存後にCosenseのページを開く」を OFF にしている。

1. アイコンをクリックしてポップアップを開く
2. 「Cosenseに保存」ボタンをクリックする
3. Cosense のページ作成画面がバックグラウンドタブで開く（現在のページから離れない）
4. ポップアップは 0.8 秒後に自動的に閉じる

### 非ゴール

- **クリップ後のページ確定の通知**: Cosense 側でユーザーが保存ボタンを押したかどうかは検知しない（URL 方式の制約 → [ADR 002](../adr/002-cosense-url-api.md)）
- **複数タブの一括クリップ**: 現在アクティブなタブのみを対象とする
- **タイトル・URL の編集**: ポップアップ上でタイトルや URL を編集する機能は提供しない
- **クリップ履歴の管理**: 過去にクリップしたページの一覧表示はしない

### 画面の流れ（ポップアップ）

```
┌────────────────────────────────┐
│ Cosense Link Clipper  ⚙ 設定  │  ← ヘッダー（emerald）
├────────────────────────────────┤
│ [警告: プロジェクト名未設定]    │  ← プロジェクト名未設定時のみ表示
│  設定を開く →                  │
├────────────────────────────────┤
│ タイトル                       │
│  [現在のタブのタイトル]         │
│ URL                            │
│  [現在のタブのURL]              │
├────────────────────────────────┤
│ [      Cosenseに保存       ]   │  ← メインボタン
│       プロジェクト: xxx         │
└────────────────────────────────┘
```

保存後:

```
┌────────────────────────────────┐
│ ...                            │
│ ✓ Cosenseで開きました！         │  ← 成功メッセージ
│ [      ✓ 保存しました      ]   │  ← ボタンが変化
└────────────────────────────────┘
```

### 未解決課題

- タブのタイトル取得が `undefined` になるケース（chrome:// / edge:// 等の特殊 URL）のエラーハンドリングは「タブ情報を取得できませんでした」のメッセージで一括処理している。より丁寧なフィードバックが必要か要検討
- ポップアップの自動クローズ（0.8秒）が短すぎると感じるユーザーもいるかもしれない

## 詳細仕様

### エントリーポイント

`src/entrypoints/popup/App.tsx`

1. `useEffect` でマウント時に以下を並行して取得:
   - `browser.tabs.query({ active: true, currentWindow: true })` で現在のタブ情報
   - `getSettings()` でプロジェクト名と保存時動作フラグ
2. 取得完了後、各 state を更新してローディングを解除
3. 「Cosenseに保存」ボタンクリック時:
   - `isValidProjectName` でプロジェクト名を検証
   - `buildCosenseUrl` で Cosense ページ作成 URL を生成
   - `browser.tabs.create({ url: cosenseUrl, active: openPageOnSave })` で新しいタブを開く
   - ステータスを `"clipped"` に変更、0.8秒後に `window.close()`

### 状態管理

| state | 型 | 初期値 | 説明 |
|---|---|---|---|
| `pageTitle` | `string` | `""` | 現在のタブのタイトル |
| `pageUrl` | `string` | `""` | 現在のタブの URL |
| `projectName` | `string` | `""` | 設定済みプロジェクト名 |
| `openPageOnSave` | `boolean` | `true` | 保存時にタブをアクティブにするか |
| `status` | `ClipStatus` | `"idle"` | `"idle"` / `"clipped"` / `"error"` |
| `errorMessage` | `string` | `""` | エラー時に表示するメッセージ |
| `isLoading` | `boolean` | `true` | 初期化中フラグ |

### ボタンの無効化条件

以下のいずれかに該当する場合、「Cosenseに保存」ボタンは非活性になる:

- プロジェクト名が未設定または空白のみ
- ページタイトルまたは URL が空
- ステータスが `"clipped"`（保存済み）
